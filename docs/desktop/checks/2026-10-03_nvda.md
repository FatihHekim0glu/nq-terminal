## Preconditions

- NVDA is installed, or its portable copy runs from a folder on D:. Do not install anything on C: for this check.
- The release is installed and starts to HOME with data.
- Open NVDA's Speech Viewer (NVDA menu, Tools, Speech Viewer) so that what is spoken is also written down. Copy its text into your evidence file at the end of each surface.
- You know your NVDA key (Insert or Caps Lock) and how to switch between browse mode and focus mode (NVDA key plus Space).

## Steps

Tick each box when what you hear matches the expectation. A mismatch that stops you doing the task, or tells you something false or nothing at all, is a finding: write it in the findings table and mark it blocking or not (the words are defined in `README.md`).

### The window

1. [ ] Start NVDA, then start the app. NVDA reads the window title as the window appears.
2. [ ] Alt+Tab away and back: NVDA reads the window title again and the page has the keyboard.

### HOME

3. [ ] On HOME, move through the page with Tab. Each stop is announced with a name and a role (for example "button", "edit", "link"), never as an unnamed "clickable" or "group" alone.
4. [ ] The four panels of HOME each have a name that says what they hold, and their figures are read with their labels (a number is never read alone when the screen shows a label beside it).
5. [ ] Move by heading (H in browse mode): the headings give a usable outline of HOME.
6. [ ] The message line and the connection state are read when they change, without you moving the focus (a live region).

### A grid

7. [ ] Open REG (or LEDG). Move into the grid. NVDA announces it as a table or grid, with its name, and the number of rows and columns.
8. [ ] Move with the arrow keys (Ctrl+Alt+arrows in browse mode): each cell is read with its column header and, where there is one, its row header.
9. [ ] The grid's own controls (sort, filter, export, where it has them) are reachable with Tab and say what they do and their state (sorted ascending, filter on).
10. [ ] The note about columns hidden at this panel size is read; maximise the panel and the extra columns appear and are read.

### A chart's table view

11. [ ] Open GP. Tab to the chart. NVDA reads its name and a short data summary.
12. [ ] With the chart focused, press T. The table view replaces the picture. NVDA announces the table with a name, its column headers and the first rows; each row reads as numbers with their headers.
13. [ ] Move through at least ten rows with the arrow keys; the dates and values are read in a sensible order.
14. [ ] Press T again: the chart returns and the focus stays on it.
15. [ ] Left and Right, with the chart focused, step the readout under the chart, and NVDA reads the new values each time.

### The command line

16. [ ] Press Ctrl+K from anywhere in the page. NVDA says the command line has the focus and its name.
17. [ ] Type a mnemonic such as `EQ` and press Enter. The result (a new panel, or an error line) is announced.
18. [ ] Type a wrong word and press Enter. The error text is read, and says what to do.
19. [ ] Press F1 with a screen open: the help is announced as it opens, and you can leave it with the keyboard alone.

### Leaving

20. [ ] Close the app with Alt+F4. NVDA does not read anything alarming; the focus returns to the previous window.
