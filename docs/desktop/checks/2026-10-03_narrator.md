## Preconditions

- The release is installed and starts to HOME with data.
- Start Narrator with the Windows logo key plus Ctrl plus Enter, and stop it the same way. Narrator may open its own Home window on first start; close it, so that it does not take the focus.
- Narrator has no transcript, so keep written notes as you go: the words you heard for each step, in your own short form. Do not rely on memory.
- You know how to switch scan mode on and off (Narrator key plus Space).

## Steps

Tick each box when what you hear matches the expectation. A mismatch that stops you doing the task, or tells you something false or nothing at all, is a finding: write it in the findings table and mark it blocking or not (the words are defined in `README.md`).

### The window

1. [ ] Start Narrator, then start the app. Narrator reads the window title as the window appears.
2. [ ] Alt+Tab away and back: Narrator reads the window title again and the page has the keyboard.

### HOME

3. [ ] Tab through HOME. Each stop is read with a name and a role, never as an unnamed item.
4. [ ] The four panels each have a name that says what they hold, and their figures are read with their labels.
5. [ ] In scan mode, move by heading (H): the headings give a usable outline of HOME.
6. [ ] The message line and the connection state are read when they change, without you moving the focus.

### A grid

7. [ ] Open REG (or LEDG). Move into the grid. Narrator reads that it is a table, its name, and the number of rows and columns.
8. [ ] Move with the arrow keys in scan mode (or Ctrl+Alt+arrows): each cell is read with its column header and, where there is one, its row header.
9. [ ] The grid's own controls (sort, filter, export, where it has them) are reachable with Tab and say what they do and their state.
10. [ ] The note about columns hidden at this panel size is read; maximise the panel and the extra columns appear and are read.

### A chart's table view

11. [ ] Open GP. Tab to the chart. Narrator reads its name and a short data summary.
12. [ ] With the chart focused, press T. The table view replaces the picture. Narrator reads the table with a name, column headers and the first rows, each row with its headers.
13. [ ] Move through at least ten rows; the dates and values come in a sensible order.
14. [ ] Press T again: the chart returns and the focus stays on it.
15. [ ] Left and Right, with the chart focused, step the readout under the chart, and Narrator reads the new values each time.

### The command line

16. [ ] Press Ctrl+K from anywhere in the page. Narrator says the command line has the focus and its name.
17. [ ] Type a mnemonic such as `EQ` and press Enter. The result (a new panel, or an error line) is announced.
18. [ ] Type a wrong word and press Enter. The error text is read, and says what to do.
19. [ ] Press F1 with a screen open: the help is announced as it opens, and you can leave it with the keyboard alone.

### Narrator and the app's keys

20. [ ] With scan mode on, the app's keys still reach the page: Alt+1 moves to a panel, Alt+K opens the key map, F8 puts the sector word on the command line. (Narrator uses some of the same keys in its own commands; a clash is a finding.)

### Leaving

21. [ ] Close the app with Alt+F4. The focus returns to the previous window and Narrator reads it.
